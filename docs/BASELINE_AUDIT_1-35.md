Evidence: `tests/infrastructure/rls-policies.test.ts`, `tenant.test.ts`. Residual (documented): ops tooling pool-role reads (BASELINE-05).
- **Facility isolation** — IMPLEMENTED at service layer (403/404 negative tests, no existence oracle; cross-facility PG read → 404). DB-level fold documented as intentional/deferred (BASELINE-02; §19).
- **IDOR** — negative-tested per-resource (patient, report, charge, notification, document, worklist, integration).
- **Secrets** — `.env.example` template only; `tests/security/secrets-sweep.test.ts` scans the repo; no committed credentials found.
- **Configuration** — startup validation rejects unknown `SDIS_*` keys (`.env.example` documents it).
- **SQL safety** — no dynamic SQL construction in `src` (parameterized queries; destructive-SQL scan 0 hits).
- **Input validation** — shared `parseUuidPath` (UUID v4 → 422), `requiredUuid` bodies, bounded vocabularies (priority, reasons, event types, channels), body limits, `nosniff`.
- **Error leakage** — stable error envelope, neutral auth message, allowlist-redacted logging, no stacks/credentials in wire or logs. Evidence: `http-contract`, `observability-http`, `auth`.
- **Audit integrity** — hash-chained append-only audit (005/016) with serialized heads + pointer-walk verification. Evidence: `audit-persistence.test.ts`.

No open CRITICAL or HIGH security finding.
